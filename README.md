# em — 인원이동 관리 웹앱

현장관리자가 스마트폰 브라우저로 현장 인원을 방(업체/작업구역) 사이에서 이동시키고, 모든 기록은 Google Sheets에 데이터 표로 쌓는 도구입니다.

```
[폰 브라우저] GitHub Pages (index.html/app.js)  ──POST──▶  Apps Script 웹앱 (doPost)  ──▶  Google Sheets
```

## 파일 구성

| 파일 | 내용 |
|---|---|
| `index.html`, `style.css`, `app.js` | 웹 화면 (프레임워크·외부 라이브러리 없음) |
| `config.js` | `API_URL` 한 줄 (PIN은 절대 넣지 않음) |
| `apps-script/Code.gs` | 시트 메뉴, 초기 설정, 출근부 생성, 집계 메뉴, 트리거, PIN, 데이터 점검 |
| `apps-script/Api.gs` | `doPost` 라우팅과 각 액션 (state/setupLoad/setupSave/addPerson/move/leave/noshow/changeType/undo/ping) |
| `apps-script/Calc.gs` | 작업시간·인건비 계산, 일별집계/일별근태 생성, `testCalc` |
| `apps-script/Sheets.gs` | 시트 이름·헤더, 읽기/쓰기 헬퍼 |
| `apps-script/appsscript.json` | 타임존 `Asia/Seoul`, V8, 웹앱 설정 |

## 배포 절차

1. **새 Google Sheets 생성** → 확장 프로그램 → Apps Script.
   - 기본 `Code.gs` 내용을 지우고, `apps-script/` 의 `.gs` 파일 4개를 같은 이름으로 만들어 붙여넣습니다.
   - 편집기 왼쪽 ⚙️ 프로젝트 설정 → "편집기에서 appsscript.json 매니페스트 파일 표시" 체크 → `appsscript.json` 내용을 붙여넣습니다 (`"timeZone": "Asia/Seoul"` 확인).
2. 시트를 새로고침 → 메뉴 **👥 인원관리 > ⚙️ 초기 설정** → 권한 승인.
   - 없는 시트만 만들고 헤더·체크박스·드롭다운·표시형식을 적용합니다. 기존 데이터는 지우지 않습니다.
3. **인원** 시트에 이름을 입력합니다 (이름을 쓰면 `사용` 체크와 구분 `현장`이 자동으로 채워짐). 현장관리자는 구분을 `현장관리자`로 바꿉니다.
4. **🔑 PIN 설정** (숫자 4~12자리), **⏰ 자동 집계 트리거 설치**.
5. (권장) 편집기에서 함수 `testCalc` 를 선택해 ▶ 실행 → 실행 로그에 `결과: 18개 통과, 0개 실패` 확인.
6. 배포 → **새 배포** → 유형: 웹 앱 → 실행: **나**, 액세스 권한: **모든 사용자** → URL 복사.
7. `config.js` 의 `API_URL` 에 URL을 붙여넣고 push → GitHub 저장소 Settings > Pages 에서 `main` 브랜치 `/ (root)` 로 활성화.
8. **코드를 고친 뒤 다시 배포할 때**는 반드시 "배포 관리 → ✏️ 편집 → 버전: 새 버전 → 배포"로 하세요. "새 배포"를 만들면 URL이 바뀝니다.

## 하루 운영

1. **아침**: 현장관리자가 웹을 열면 오늘 세팅 전이면 **아침 세팅 화면**이 먼저 나옵니다.
   근태(출근/반차/연차…)·시간·첫 배치 방을 고르고 **[세팅 완료]**. `어제 배치 불러오기`로 최근 근무일의 첫 배치 방을 채울 수 있습니다.
2. **낮**: 이름 칩 터치 → 방 버튼 터치 (확인창 없음, 8초 안에 토스트의 [취소]로 되돌리기). 조퇴/미출근/근태 변경도 같은 하단 시트에서 합니다.
   - 원칙: **오는 게 기본, 안 오면 그때만 [미출근]**. 지각자는 "미출근 → 도착하면 배치"만 하면 배치 시각부터 계산됩니다.
   - 반차자는 예정 시작 전엔 "출근 예정"으로, 예정 시작이 되면 자동으로 근무/미배치로 바뀝니다. 예정 종료가 지나면 자동으로 퇴근 영역으로 내려갑니다 (이벤트는 기록되지 않음).
3. **18:30 무렵**: 트리거가 `일별집계`·`일별근태`·`일별방집계`를 다시 만듭니다. 시간 열(작업시간·유급휴가시간)은 `1시간20분`처럼 보이지만 숫자라서 합계가 됩니다. 피벗에서 합계가 소수로 보이면 그 열을 선택하고 서식 → 숫자 → 맞춤 숫자 형식에 `[h]"시간"mm"분"`을 넣으세요. `일별방집계`는 날짜×방마다 인원수·작업시간·인건비 한 줄(유급휴가 제외, 미배치 포함)입니다. 시트 관리자는 `일별집계`에 피벗을 걸어 방별/사람별/월별을 봅니다 (`구분=작업`만 보면 방별 작업 인건비, 전체면 총 인건비).

**더 이상 안 나오는 사람(퇴사·장기 미출근)**은 매일 미출근→휴무로 넣지 말고 **명단에서 제외**하세요.
- 세팅 화면: 근태 칩 터치 → 맨 아래 **[명단에서 제외]** / 메인 화면: 이름 칩 터치 → **[명단에서 제외]** (현장 배치 기록이 없을 때)
- 인원 시트 `사용`이 꺼지고 메모에 `제외 날짜 처리자`가 남습니다. 오늘 배치 기록이 없으면 오늘 출근부 행도 지워져 바로 사라지고, 배치 기록이나 연차 같은 유급 기록이 있으면 오늘 기록은 남기고 내일부터 빠집니다.
- 다시 나오면 **[+ 인원 추가]**에 같은 이름을 넣으면 되살아납니다.
- **세팅에서 잘못 추가한 인원**(오타, 중복 등)은 근태 칩 → **[인원 삭제 (잘못 추가됨)]**로 인원 시트 행까지 지웁니다. 지난 출근 기록이나 오늘 현장 기록이 없는 사람에게만 이 버튼이 나오고, 기록이 있는 사람은 [명단에서 제외]가 나옵니다. 인원 시트엔 없고 오늘 출근부에만 남은 이름도 같은 방법으로 지울 수 있습니다.

시트 관리자 메뉴: 📋 오늘 출근부 생성(웹을 못 쓰는 날 대비), 📊 오늘 집계 실행, 📅 날짜 지정 집계, ✅ 데이터 점검.

## 구현하면서 정한 것 (명세가 모호했던 부분)

- 명세의 테스트 항목 "B 405분/101,250원"은 계산 예시 표(B 240분/60,000원, C 180분)와 맞지 않아서 **예시 표를 기준**으로 구현·검증했습니다.
- `사용` 칸이 **비어 있으면 사용으로 간주**합니다 (체크를 해제해서 FALSE가 된 행만 미사용). 시트에 이름을 쓰면 `onEdit`가 사용 칸을 자동 체크합니다.
- 시간 칸은 1899년 날짜 변환 오차를 피하려고 **표시값(HH:mm)으로 해석**합니다. 스크립트가 쓰는 시작/종료는 "그날 날짜 + 시각" Date로 저장하고 표시형식만 `hh:mm` 입니다.
- **근태 변경**은 명세의 출근예정·미배치·미출근 외에, 아침에 세팅배치만 해두고 아직 실제 배치 기록이 없는 사람(화면상 "근무")도 허용합니다. 유효 이벤트가 세팅배치/미출근뿐일 때만 됩니다.
  - 세팅배치는 항상 취소합니다. 미출근 이벤트는 새 근태의 시작 시각이 아직 안 됐으면(예: 미출근 → 오전반차) 취소하고, 이미 지났으면(예: 미출근 → 다시 출근) 그대로 둬서 인건비가 잘못 붙지 않게 했습니다.
- 예정 종료가 지나 자동 퇴근 표시된 사람은 이동/조퇴 불가 (`BAD_STATE`). 시간을 바꾸려면 세팅 수정에서 종료시간을 고칩니다.
- `suggestedRoom`(어제 배치 불러오기)은 `배치`뿐 아니라 `세팅배치`도 첫 배치로 봅니다 (아침 세팅이 주 입력 경로이므로).
- 동시 세팅 충돌: 세팅 화면을 연 뒤 다른 사람이 저장했으면 서버가 `SETUP_CHANGED`를 돌려주고, 화면에서 "덮어쓰기 / 최신 불러오기"를 고릅니다. 현장 근태 변경도 세팅일시를 갱신하므로 이 안내가 뜰 수 있습니다.
- 세팅 저장에서 일부가 실패하면 나머지는 저장하고 세팅 화면에 머물면서 실패한 줄에 빨간 안내를 띄웁니다 (전원 성공일 때만 메인으로 이동).
- 자동 집계 트리거는 Apps Script 특성상 지정 시각 **±15분** 안에 실행됩니다.
